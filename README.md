### 🧑‍💻 About me

M.Tech student in Computer Science & Information Security at **IIIT Hyderabad**, building my
career in **AI/ML, Natural Language Processing and LLM systems**.

I like understanding models from the inside out. My main project so far is a pair of transformer
language models written completely from scratch in PyTorch, without using any framework's
attention or transformer classes.

Before this I spent 4.5 years as a Project Engineer at L&T Construction. That job taught me how
to stay calm when something breaks at 2 AM, which turns out to be useful in software too.

- 🔭 **Currently building:** a distributed LLM inference engine with pipeline parallelism
- 📚 **Currently learning:** Digital Image Processing and Computer Vision
- 🧩 **Problem solving:** 700+ DSA problems on LeetCode and GeeksforGeeks

<details>
<summary><b>More on the language models</b></summary>
<br>

I implemented multi-head causal self-attention, RoPE positional embeddings and causal masking
myself, then trained both models on 1.2B+ tokens I collected and cleaned. The ablation removed
positional information entirely to see what actually breaks: the model does not fail evenly, it
rebuilds a rough sense of position in a few middle layers.

</details>
